Mentions légales du site Flexarion

Flexarion est un projet fictif. Ce site a été créé dans le cadre d'un concours de référencement entre groupes d'étudiants du BUT Informatique de l'IUT d'Aix-Marseille.

Nature fictive du projet

  • Le studio Flexarion, le jeu Below Zero, leurs personnages et leur histoire sont entièrement fictifs.
  • L'équipe de développement présentée sur ce site n'existe pas : les noms et les rôles des huit membres sont inventés. Toute ressemblance avec des personnes réelles serait fortuite.
  • Ce site est un projet pédagogique réalisé dans le cadre du module « Plan de communication et webmarketing à l'ère de l'IA » du BUT Informatique, 2e année, de l'IUT d'Aix-Marseille (département Informatique). Il participe à un concours SEO entre groupes d'étudiants autour du mot-clé « Flexarion ».
  • Aucun produit n'est vendu et aucun service n'est proposé. L'adresse e-mail indiquée sur le site est fictive.

Éditeurs du site

Ce site est édité, à titre non commercial, par les étudiants suivants, véritables créateurs du projet :

Hébergement

Le site est hébergé par GitHub Pages, service de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, États-Unis (pages.github.com). Le code source est publié sur l'organisation GitHub flexarion-officiel.

Usage de l'intelligence artificielle

Conformément aux consignes du projet, l'usage de l'IA est documenté :

  • Les visuels du site (logo, illustrations, concept arts, captures de travail) ont été générés par intelligence artificielle et pourront être retravaillés par les étudiants.
  • Les textes et le code du site ont été produits avec l'assistance d'un agent IA, à partir de l'identité de marque définie par les étudiants.
  • Le détail des outils et des consignes utilisés est tenu dans le journal d'usage de l'IA du projet (fichier docs/RAPPORT.md du dépôt).

Données personnelles et cookies

Ce site ne dépose aucun cookie, n'utilise aucun outil de mesure d'audience ni de publicité, et ne collecte aucune donnée personnelle via un formulaire. L'hébergeur GitHub peut enregistrer des journaux techniques (adresse IP notamment) pour des raisons de sécurité, selon sa propre politique de confidentialité.

Propriété intellectuelle

Les textes et visuels de ce site sont réalisés pour un usage pédagogique. Ils ne peuvent pas être réutilisés à des fins commerciales sans l'accord des étudiants éditeurs. Les noms de lieux réels (Aix-en-Provence, cours Mirabeau, Sainte-Victoire…) ne sont utilisés que comme cadre de fiction.

Liens

Conformément au règlement du concours, ce site ne contient aucun lien vers les sites des autres groupes participants.
