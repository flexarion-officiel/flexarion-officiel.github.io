# Compte rendu de la v1.2.0 du site

## Appréciacion globale
Le site commence à avoir une très bonne apparence. L'effet « plat » et fade qui pouvait apparaitre dans les premières versions commence à s'effacer. On va faire ici un travail plus en détail sur les animations.

## Animations

### Header
- (PC) : Faire une animation légère lors du survol des liens du menu de navigation
- (Mobile) : Faire une animation ease-in-out pour le pliage/dépliage du menu burger
- Pour les cartes de type FAQ : Faire une animation ease-in-out pour le pliage/dépliage des cartes
- Pour les éléments de classe "facts" : Supprimer l'animation qui les fait bouger légèrement vers le haut
- Pour les boutons : faire une animation pour le changement de couleur lors du survol

## Important
Les animations du site doivent être un élément en plus, qui sert uniquement au confort des yeux. Il ne faut donc pas en faire trop, c'est à dire :
- Faire des animations trop longues
- Faire des animations trop détaillées
- etc
car sinon on risque de perdre en fluidité de navigation.
